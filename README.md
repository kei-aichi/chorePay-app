# お小遣い管理アプリ

## 概要

子供のお手伝い管理アプリです。
お手伝いを記録し、お小遣いを自動集計できます。

---

## 作成背景

子供のお手伝いを楽しく習慣化するために作成しました。

---

## 主な機能

- ユーザー登録
- ログイン機能
- お手伝い登録
- お小遣い集計
- 履歴確認

---

## 使用技術

- PHP 8.4
- Laravel 12
- MySQL 8.0
- Docker
- Laravel Sail
- Tailwind CSS
